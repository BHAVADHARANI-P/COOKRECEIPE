# 🍳 RecipeMagic - Premium Recipe Sharing Platform

Welcome to **RecipeMagic**, a high-end full-stack culinary platform where food lovers can discover, share, and manage their favorite recipes with a beautiful, modern interface.

## 🚀 Live Demo
**Website**: [https://cookreceipe-4.onrender.com](https://cookreceipe-4.onrender.com)

---

## ✨ Features
- **Premium Design**: Glassmorphic UI with Material-UI, Framer Motion animations, and high-resolution culinary imagery.
- **Full-Stack Performance**: Built with React, Vite, Node.js, and Express.
- **Zero-Config Database**: Automatically uses an in-memory MongoDB fallback for instant local exploration.
- **Auto-Seeding**: Pre-populated with delicious example recipes and an admin account.
- **Authentication**: Secure JWT-based login and signup.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.

---

## 🛠️ Tech Stack
- **Frontend**: React, Vite, Material-UI (MUI), Framer Motion
- **Backend**: Node.js, Express, Mongoose
- **Database**: In-Memory MongoDB (Local/Demo)
- **Deployment**: Render

---

## 💻 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/BHAVADHARANI-P/COOKRECEIPE.git
   cd COOKRECEIPE
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run server
   ```
   The app will be available at `http://localhost:3000`.
